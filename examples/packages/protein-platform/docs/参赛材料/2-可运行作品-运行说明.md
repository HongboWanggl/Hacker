## 二、从源码复现运行

仓库：本参赛材料所在 git 仓库（`examples/packages/protein-platform` 为主体）。

1. **依赖**：Node.js（含 npm）；可选 Python 3.10+ venv 安装 `boltz_community==2.10.12`（本地推理兜底档；不装则自动落到托管 API 或提示配置，平台不会因此不可用——**三个业务包运行时零 npm 依赖**）。
2. **安装 surface**：在 AGH 环境执行 `agnes` 的 surface 安装/更新流程（仓库内 `scripts/agh-update-platform.mts` 一键完成 build → inspect → update → trust → enable）。
3. **信任并启用**：`agnes profile trust`，确认 `agnes.surfaces` 中平台处于 enabled。
4. **可选配置**（均通过环境变量，不进代码）：
   - `BOLTZ_WORKER_URL`：GPU worker 地址（默认 `http://127.0.0.1:7610`，探活 1.5 s 失败即跳过该档）；
   - `BOLTZ_API_KEY`：Boltz 托管 API 密钥（自购，第二档）；
   - `PP_USER` / `PP_PASS`：Caddy Basic Auth 凭据（探针用）。
5. **验证安装**：浏览器打开平台首页粘贴 `P69905` 提交单体预测，约 1–4 分钟出结果即部署成功；顶栏「基准」页应能打开 CASP14 十靶标打分表。

## 四、专业工具与设备接口

- AGH（Agnes Harness）智能体运行底座：会话管理、工具/服务注册、事件流；
- Caddy 2.10.2（Apache-2.0）：HTTPS 反代与 Basic Auth；
- 自建 GPU worker：HTTP `/health` 探活 + `/predict` 提交，超时 22 min，失败自动落回下一档；
- 无特殊硬件要求：GPU worker 缺席时平台照常工作（走 API/本地档），只是速度不同。
