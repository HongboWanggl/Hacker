一、作品内容

ProteinLens 是一个浏览器即开即用的蛋白质结构预测与置信度判读工作台。它把过去散落在命令行、Python/GPU 环境与多个预测工具之间的整条链路收进一个网页：用户输入 UniProt ID、原始序列或 FASTA（也支持用一句自然语言描述目标蛋白，平台自动检索候选），平台即开启一个智能体会话，由会话内的模型自主规划并调用预测工具完成结构折叠，最终给出带完整置信度体系的结果。它同时是一个平台自检的作品：平台自身接受国际公开学术基准 CASP14 的检验，把预测结果与 RCSB 实验解析结构逐靶比对、由服务端独立复算精度分数，并把模型自报置信度与实测值的校准关系公开成图，包括对自己不利的部分。

要解决的真问题。对非生物信息学用户，真正的门槛不是有没有工具，而是三件事。一是环境门槛，主流工具需要命令行、Python 与 GPU 环境，多工具之间还要手动拼装；二是判读门槛，产出一个 PDB 文件不等于可用结果，同一套单序列从头预测流程在 CASP14 靶标上的精度谱横跨 0.29 到 0.95（Cα-lDDT），普通用户却缺乏判断这次预测可不可信的能力；三是验证门槛，谁都能展示一张漂亮的结构图，少有人让第三方基准来检验自己的输出。本作品把这三件事合成一个整体：预测、置信度判读、外部基准自检。

面向两类用户。零生信背景的用户不必安装任何软件，打开网页即可完成预测，并通过 pLDDT 着色、置信度曲线、分段统计一眼判断可信度；Agnes Harness 生态的科研助手场景，则用一个真实科研工作流（任务规划、工具编排、结果验证、外部基准检验）验证通用智能体底座承接专业科学任务的能力。

二、实现方案

总体架构是一条完整数据通路：浏览器（平台前端）经 Caddy 2.10.2 反向代理与登录门（forward_auth 会话 cookie）到达平台服务端（Node 与 TypeScript），再下到 Agnes Harness（AGH）daemon 与 agent 会话，由会话调用 AGH 工具与服务、进而调用外部模型与数据接口，最后回到服务端归档与基准打分。

AGH 不是可选组件而是执行底座：每个预测任务对应一个 AGH agent 会话，通过 sdk.session.new({ cwd, preset: 'standard' }) 创建，并以 session.prompt 注入按任务类型生成的结构化提示词；agent 在会话内规划取序列、折叠预测、置信度分析的执行顺序。模型真的在做决策而非跑硬编码流水线，最直接的证据是长链靶标 T1024（408 aa 膜蛋白）的会话日志：predict_structure 对超过 1000 aa 直接拒绝，约 400 aa 送公共 ESMFold 端点被拒（HTTP 413），agent 读取该失败信息后自主改档、改调 predict_complex 走 Boltz-2 长链档。

能力注册分两层。工具层注册 predict_structure（单体预测）、predict_complex（复合物与长链）、batch_predict（批量）、uniprot_search（序列检索）、compare_with_alphafold（与参考结构对比）；服务层注册 protein.structure（链感知结构解析）、protein.report（报告渲染）、protein.pae（PAE 热图数据）、protein.file（产物读取）。

过程可观测。前端进度页不是猜出来的，而是对 session.events() 做账本式归约：每次工具调用都留有工具开启、结果关闭的成对事件，进度页把它们实时映射成阶段点亮，因此执行中呈现与真实状态严格一致，不会出现假进度。断线可恢复：页面关闭或刷新后通过 sdk.session.load 重连会话并回放事件日志，任务不丢、进度照常、结果照常出现，前端只是观察窗口。

三级算力路由是核心工程方法之一。预测请求按自建 GPU worker、托管 API、本地开源权重三级分发，任一级失败静默落回下一级。第一级是家用 RTX 4060，经反向 SSH 隧道挂载为服务器本机 127.0.0.1:7610，提交窗口 22 分钟，worker 侧为串行 GPU 队列、双端只绑回环并以 token 鉴权；第二级是团队自购的 Boltz 托管 API；第三级是 VPS 上的开源权重 boltz_community 2.10.12（MIT）。三级都不可用时返回可执行的配置提示而非静默失败。关键取舍是：worker 永远只是加速器而非依赖项，GPU 机器关机时该档静默消失、任务照常完成，只是速度不同，已由真实停隧测试验证。

会话内模型为 Agnes 3.0 Flash（agnes-3.0-flash），经 Agnes AI 网关以 OpenAI 兼容协议调用，原生工具调用、200K 上下文；网关抖动时由备用路由 Doubao Seed 2.0 Pro 接管，对上层透明。证据是平台会话库中 agnes-3.0-flash 出现 265 处、备用模型 0 处，且每个任务的会话事件流中都能看到该模型发起的工具调用事件。

部署环境。公网入口为腾讯云轻量应用服务器直连（裸 IP 无 TLS 证书，走 http 明文；WebSocket 走 ws://118.25.194.247/agnesd）；反代与登录门用 Caddy 2.10.2，以 forward_auth 实现会话 cookie 登录，替代早期 HTTP Basic Auth。工具码有发布纪律：daemon 只加载 profile 安装快照，改代码必须走 agh-update-pkg 并校验安装目录哈希再重启。前端 3D 结构、PAE 热图与缩略图全部由项目自有代码实时生成（Canvas 与 WebGL），未使用任何第三方图片、字体或 3D 资产；三个业务包运行时零 npm 依赖。

三、核心功能

输入识别与前置校验。提交之前就让用户看到平台读到了什么、会丢掉什么。粘贴 P69905 识别为 UniProt ID；粘贴序列识别为原始序列并给出长度；粘贴多条 FASTA 取首条并提示其余将忽略；序列里混入数字则黄条警告无法识别为序列；输入一句描述（如 p53 human）识别为自然语言描述、将检索 UniProt 候选；批量页签输入 10 个 ID 会提示最多 8 个、仅取前 8 个，服务端同样只处理前 8 个（前端与归档双侧一致，显式截断）；复合物页签统计总链数与总长，并对不足 5 aa 的链提示将被忽略。

任务与结果呈现。支持单体预测、复合物预测（多链加配体 SMILES）、批量预测，提交后进入阶段进度页（取序列、折叠预测、置信度分析）。结果页自带完整置信度体系：3D 结构可拖拽旋转与滚轮缩放，按 pLDDT 逐残基着色（蓝为高置信、红为低置信）；置信度曲线悬停某残基时 3D 上对应位置联动高亮，支持序列条拖选区段；分段统计自动列出连续低置信区段，直接告诉用户哪一段不可信；复合物另有链间置信度 ipTM、整体 pTM、配体结合概率，以及 PAE 误差热图（0 到 32 埃色标，点击可回读具体残基对误差）。

归档、报告墙与分享。任务完成后由服务器拉取工作区产物归档，因此换设备、换会话打开全部任务时结果页可完整重建，不依赖原页面在线；报告墙支持类型筛选、标题搜索与最高分排序。任意结果可导出自包含 HTML 报告，内嵌 PNG 快照、pLDDT 评分、完整报告数据以及一个可拖拽旋转的交互式 3D 视图，实测约 12 万字节，在无网络、无平台的本地环境仍可打开与交互。

外部能力与基准自检。对单体结果可调用 compare_with_alphafold，以 Horn 四元数最优叠合计算 Cα-RMSD，核心区小于 2 埃判定为与参考高度一致；顶栏检索页可结构化搜索（如 hemoglobin）并支持行内一键预测与勾选多条批量预测。基准页用 CASP14 公开靶标集在公网真实管线上运行，以 RCSB 实验解析结构为真值，由服务端独立复算 Cα-lDDT 与 Cα-RMSD 并输出 pLDDT 校准直方图；十个公开靶标（106 到 408 aa）中九个完成自动打分，一个 408 aa 膜蛋白如实显示待运行。

异常处理。网关抖动自动重试最多两次，401 鉴权失败自动换头重试；失败任务如实展示失败原因并提供一键原样重跑；运行中支持两键取消，取消态与失败态严格区分；GPU worker 缺席时静默落回 API 或本地档，任务照常完成。

四、技术亮点

第一，智能体底座是真用而不是套壳。多数应用把模型当文本生成器，本作品中 AGH 承担的是执行底座（会话管理、能力注册、工具编排、事件流回放、断线恢复），这是页面只是观察窗口这一卖点的技术前提；而 T1024 日志中 ESMFold 413 后读取失败信息、自主换档 Boltz-2 的完整链路，是模型决策能力的直接证据。

第二，三级算力路由与零依赖降级，把家用 GPU 不稳定这一现实约束转化成对用户不可见的实现细节。

第三，把结果可不可信做成产品功能，这是本作品与同类工具最本质的区别。置信度体系让非专业用户也能判读质量，而校准直方图进一步检验模型自报的置信度是否诚实：实测两者高度一致，如 T1025 自报 94.6 对实测 95.2、T1046s2 自报 85.0 对实测 85.9，也存在 T1056 自报 70.3 而实测 81.7 的偏保守情形，偏离也如实进图。

第四，平台自身接受外部学术基准检验。把 CASP14 公开靶标集接入真实管线，用 RCSB 实验结构做真值、服务端独立复算，逐靶公开参考 PDB ID 供复核。已完成的九个靶标成绩头部突出：T1025 达 Cα-lDDT 0.952、全残基 Cα-RMSD 0.65 埃，T1030 为 0.943、T1046s2 为 0.859、T1056 为 0.817；同时如实呈现 0.29 到 0.52 的低分档，分数谱全谱公开、不做挑选。另有独立参考锚点：血红蛋白 α（P69905）预测与 AlphaFold DB 参考结构核心区 Cα-RMSD 为 0.31 埃。

第五，诚实工程，把失败也做成可验证的证据。408 aa 膜蛋白 T1024 三次公网运行均未完成，平台如实显示待运行，不粉饰、不重试赌博。排查过程反而最完整：前两次失败源于两处分层超时缺陷，worker HTTP 服务默认 300 秒请求超时、客户端默认 300 秒头部超时，长链折叠常超过 5 分钟导致响应被提前掐断，且错误被降级提示掩盖、极易误判为缺少 API key；两处缺陷均已定位修复，并顺带修正了包发布链路。第三次全部修复生效后被团队保留的单任务 20 分钟保护上限终止，真瓶颈是长链折叠依赖的公共 MSA 服务排队时长不可控（同日实测 14 分钟与超过 20 分钟两档，GPU 推理本身仅约 2 分钟），worker 侧留有同日完整折叠产物（pTM 0.78、pLDDT 0.905）为证；团队按设计取舍不放宽上限，三次会话日志与修复提交链公开可溯。

第六，结果验证具有独立性，基准打分在服务端完成，不依赖前端、不依赖页面在线。

第七，可复现性。仓库内附探针套件，覆盖归档装配 13 项、预测流全生命周期 42 项、Cα-lDDT 打分数学 22 项，共 77 项单元断言，另有公网端到端探针；typecheck 与 lint 门禁干净，关键分数、比对结论与复现命令一一对应，可供现场抽查。
