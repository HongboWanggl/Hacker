作品名称：ProteinLens 蛋白透镜——基于 Agnes Harness 的蛋白质结构预测与置信度判读工作台
参赛组别：本科生组｜南京大学｜王宏博（人工智能学院）、周游（医学院）
在线体验：http://118.25.194.247/platform/（演示账号 guest，可提交任务、查看与下载结果，仅不能删除归档）

一、作品内容

输入 UniProt ID、原始序列或 FASTA（也支持一句自然语言描述，平台自动检索候选），平台在 Agnes Harness（AGH）上开启一个智能体会话，由会话内的模型自主规划并调用预测工具完成结构折叠，再给出可直接判读的置信度体系。平台已经过国际公开学术基准 CASP14 的检验。

二、实现方案

每个任务＝一个 AGH agent 会话：能力经 agnes.registerTool 与 ctx.services.register 注册，由模型在会话内规划"取序列、折叠预测、置信度分析"的顺序并调用。

过程可观测：对会话事件流做账本式归约，阶段进度由真实的工具开启与结果事件驱动，与实际执行状态一致。断线可恢复：页面关闭或刷新后重连会话并回放事件日志，任务不丢，前端只是观察窗口。

三级算力路由：自建 GPU worker（家用 RTX 4060，经反向 SSH 隧道挂载）→ 托管 API → 本地开源权重，逐级静默降级。模型为 Agnes 3.0 Flash 主档，网关抖动时由备用路由 Doubao Seed 2.0 Pro 接管。前端 3D 结构、热图与缩略图全部由自有代码实时生成，未用任何第三方图片/字体/3D 资产；三个业务包运行时零 npm 依赖。

三、核心功能

三类任务：单体预测、复合物预测（多链加配体 SMILES）、批量预测。

提交前实时识别输入并预警：识别 UniProt ID／序列／FASTA／自然语言描述并给出长度；多条 FASTA 提示其余忽略；混入数字黄条警告；批量超过 8 个显式提示"仅取前 8 个"，服务端同样只处理前 8 个——前端与服务端双侧一致，超限部分显式提示。

结果判读：3D 结构按 pLDDT 逐残基着色，置信度曲线悬停时 3D 对应残基联动高亮，自动统计连续低置信区段；复合物另有 ipTM、pTM、配体结合概率与 PAE 误差热图（可回读具体残基对的误差）。

归档与分享：结果由服务器归档，换设备打开"全部任务"仍能完整重建；报告墙支持筛选、搜索与最高分排序；任意结果可导出为自包含 HTML 报告，内嵌快照、评分与可拖拽旋转的交互式 3D 视图，实测约 12 万字节，离线可交互。

外部能力：与 AlphaFold DB 对比（Horn 四元数最优叠合算 Cα-RMSD）；UniProt 检索后一键预测。异常处理：抖动自动重试最多两次、失败原因明确展示并可一键重跑、两键取消、GPU worker 缺席静默降级。

四、技术亮点

1. 智能体底座承担真实执行职责。会话管理、能力注册、工具编排、事件流回放、断线恢复全部由 AGH 实现。硬证据在长链预测的会话日志里：predict_structure 拒收超过 1000 aa 的长链，送公共 ESMFold 端点被拒（HTTP 413）后，agent 读取该失败信息自主改调 predict_complex 走 Boltz-2 长链档——换档是模型在会话内自己决策的，不是代码写死的分支。

2. 结果可判读，且置信度可被检验。平台公开 pLDDT 校准直方图（模型自报 vs 服务端实测），实测高度一致（T1025 自报 94.6 对实测 95.2，T1046s2 自报 85.0 对实测 85.9），结果页直接回答"这次预测可不可信"，而不只是交付一个结构文件。

3. 平台经过外部学术基准检验。在 CASP14 公开靶标集上，以 RCSB 实验解析结构为真值，由服务端独立复算 Cα-lDDT 与 Cα-RMSD；头部成绩：T1025 达 Cα-lDDT 0.952、全残基 Cα-RMSD 0.65 埃，T1030 0.943，T1046s2 0.859，T1056 0.817。另有独立参考锚点：血红蛋白 α（P69905）预测与 AlphaFold DB 参考结构核心区 Cα-RMSD 0.31 埃。逐靶参考 PDB ID 公开，评审可现场复核。

4. 三级算力路由把"家用 GPU 不稳定"变成用户看不见的实现细节。GPU worker 缺席时该档静默消失、任务照常完成，只是更慢——已用真实停隧测试验证。服务器本身无 GPU，功能完整不受影响。

5. 可复现、可抽查。仓库内附 77 项单元断言（归档装配 13、预测流全生命周期 42、Cα-lDDT 打分数学 22）与公网端到端探针，typecheck 与 lint 门禁干净；文中每一个分数都能在平台或仓库里当场复核。
