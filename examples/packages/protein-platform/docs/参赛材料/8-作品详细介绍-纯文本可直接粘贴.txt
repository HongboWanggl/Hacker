作品名称：ProteinLens 蛋白透镜——基于 Agnes Harness 的蛋白质结构预测与置信度判读工作台
参赛组别：本科生组｜南京大学｜周游（医学院）、王宏博（人工智能学院）
在线体验：http://118.25.194.247/platform/（演示账号 guest，可提交任务、查看与下载结果，仅不能删除归档）

一、作品内容

ProteinLens 是一个浏览器即开即用的蛋白质结构预测与置信度判读工作台。用户输入 UniProt ID、原始序列或 FASTA（也支持用一句自然语言描述目标蛋白，平台自动检索候选），平台即开启一个智能体会话，由会话内的模型自主规划并调用预测工具完成结构折叠，最后给出带完整置信度体系的结果。

要解决的问题有三个。一是环境门槛：主流预测工具需要命令行、Python 与 GPU 环境，多个工具之间还要手动拼装。二是判读门槛：产出一个 PDB 文件不等于可用结果，同一套单序列从头预测流程在 CASP14 靶标上的精度横跨 0.29 到 0.95（Cα-lDDT），普通用户却无法判断这次预测可不可信。三是验证门槛：谁都能展示一张漂亮的结构图，少有人让第三方基准来检验自己的输出。本作品把预测、置信度判读、外部基准自检合成一个整体。

平台同时是一个"自检"的作品：它把 CASP14 公开靶标集接入自己的真实管线运行，以 RCSB 实验解析结构为真值、由服务端独立复算精度分数，并把模型自报置信度与实测值的校准关系公开成图，包括对自己不利的部分。

二、实现方案

总体架构：浏览器 → Caddy 反向代理与登录门（forward_auth 会话 cookie）→ 平台服务端（Node 与 TypeScript）→ Agnes Harness（AGH）daemon → agent 会话 → AGH 工具与服务 → 外部模型与数据接口；任务完成后回到服务端归档与基准打分。

每个任务等于一个 AGH agent 会话，由会话内的模型规划"取序列、折叠预测、置信度分析"的执行顺序并调用工具。模型确实在做决策而不是跑死流水线：长链靶标 T1024（408 aa 膜蛋白）的会话日志显示，predict_structure 对超过 1000 aa 直接拒绝，约 400 aa 送公共 ESMFold 端点被拒（HTTP 413）后，agent 读取该失败信息自行改调 predict_complex，走 Boltz-2 长链档完成折叠。

平台向 AGH 注册两类能力。工具层：predict_structure（单体预测）、predict_complex（复合物与长链）、batch_predict（批量）、uniprot_search（序列检索）、compare_with_alphafold（与参考结构对比）。服务层：protein.structure（链感知结构解析）、protein.report（报告渲染）、protein.pae（PAE 热图数据）、protein.file（产物读取）。

过程可观测、断线可恢复。前端进度页是对会话事件流做账本式归约：每次工具调用都留有"开启、结果"成对事件，进度页把它们映射为阶段点亮，所以不猜进度、不会出现假进度。页面关闭或刷新后，平台重连会话并回放事件日志，任务不丢、结果照常出现——前端只是观察窗口。

三级算力路由。预测请求按"自建 GPU worker、托管 API、本地开源权重"三级分发，任一级失败静默落回下一级。第一级是家用 RTX 4060，经反向 SSH 隧道挂载为服务器本机 127.0.0.1:7610，串行 GPU 队列、双端只绑回环并以 token 鉴权；第二级是团队自购的 Boltz 托管 API；第三级是服务器本地的开源权重 boltz_community 2.10.12。关键取舍是：worker 只是加速器而不是依赖项——GPU 机器关机时该档静默消失，任务照常完成，只是更慢，这一点已由真实停隧测试验证。

会话内模型为 Agnes 3.0 Flash（agnes-3.0-flash），经 Agnes AI 网关以 OpenAI 兼容协议调用；网关抖动时由备用路由 Doubao Seed 2.0 Pro 接管，对上层透明。依据是平台会话库中 agnes-3.0-flash 出现 265 处、备用模型 0 处，且每个任务的会话事件流中都能看到该模型发起的工具调用。

部署与实现约定。公网入口是腾讯云轻量服务器直连，裸 IP 无 TLS 证书故走 http，WebSocket 走 ws://118.25.194.247/agnesd；反代与登录门用 Caddy 2.10.2 的 forward_auth 实现，替代早期 HTTP Basic Auth。改工具代码必须经发布流程写入 profile 安装快照（daemon 只加载快照，只改源码树不生效）并校验哈希后重启。前端 3D 结构、PAE 热图与缩略图全部由项目自有代码实时生成，未使用任何第三方图片、字体或 3D 资产；三个业务包运行时零 npm 依赖。

三、核心功能

输入识别与前置校验：提交之前就让用户看到平台读到了什么、会丢掉什么。UniProt ID、原始序列、FASTA 分别识别并给出长度；多条 FASTA 取首条并提示其余将忽略；序列里混入数字则黄条警告；输入一句自然语言（如 p53 human）识别为"将检索 UniProt 候选"；批量输入 10 个 ID 会提示"仅取前 8 个"，服务端同样只处理前 8 个，显式截断、不静默丢弃；复合物统计链数与总长度，并忽略不足 5 aa 的链。

三类任务：单体预测、复合物预测（支持多链加配体 SMILES）、批量预测。

结果判读，这是本作品的核心价值。3D 结构可拖拽旋转与滚轮缩放，按 pLDDT 逐残基着色（蓝为高置信、红为低置信）；置信度曲线悬停某残基时，3D 上对应位置联动高亮；分段统计自动列出连续低置信区段，直接指出哪一段不可信；复合物另有链间置信度 ipTM、整体 pTM、配体结合概率，以及 PAE 误差热图（0 到 32 埃色标，可回读具体残基对的误差）。

归档与分享：结果由服务器归档，换设备或换会话打开"全部任务"仍能完整重建，不依赖原页面在线；报告墙支持类型筛选、标题搜索与最高分排序；任意结果可导出为自包含 HTML 报告，内嵌结构快照、评分与可拖拽旋转的交互式 3D 视图，实测约 12 万字节，在纯本地环境也能打开与交互。

外部能力与基准页：单体结果可调用 compare_with_alphafold 与 AlphaFold DB 参考结构对比，用 Horn 四元数最优叠合计算 Cα-RMSD，核心区小于 2 埃判定为"与参考高度一致"；检索页可搜索 UniProt 并一键预测。基准页用 CASP14 十个公开靶标（106 到 408 aa）在公网真实管线上运行，以 RCSB 实验结构为真值、服务端独立复算 Cα-lDDT 与 Cα-RMSD，并输出 pLDDT 校准直方图；十个靶标中九个完成自动打分，一个 408 aa 膜蛋白如实显示"待运行"。

异常处理：网络抖动自动重试最多两次，鉴权失败自动换头重试；失败任务如实展示失败原因，并可一键原样重跑；运行中支持两键取消，取消态与失败态严格区分，用户主动取消不会被记为错误；GPU worker 缺席时静默降级到 API 或本地档，任务照常完成。

四、技术亮点

1. 智能体底座是真用，不是套壳。多数应用把模型当文本生成器，这里 AGH 承担的是执行底座：会话管理、能力注册、工具编排、事件流回放、断线恢复，这是"页面只是观察窗口"这一能力的技术前提。T1024 日志里"被拒后读取错误信息、自主换档"的完整链路，就是模型决策能力的直接证据。

2. 三级算力路由与零依赖降级，把"家用 GPU 不稳定"这一现实约束，转化成用户看不见的实现细节。

3. 把"结果可不可信"做成产品功能，这是与同类工具最本质的区别。置信度体系让非专业用户也能判读质量；校准直方图进一步检验"模型自报的置信度是否诚实"——实测两者高度一致（T1025 自报 94.6 对实测 95.2、T1046s2 自报 85.0 对实测 85.9），也存在 T1056 自报 70.3 而实测 81.7 的偏保守情形，偏离同样如实进图。

4. 平台自愿接受外部学术基准检验。九个已完成靶标的成绩头部突出：T1025 达 Cα-lDDT 0.952、全残基 Cα-RMSD 0.65 埃，T1030 为 0.943、T1046s2 为 0.859、T1056 为 0.817；0.29 到 0.52 的低分档同样公开，全谱呈现、不做挑选。另有一个独立参考锚点：血红蛋白 α（P69905）预测与 AlphaFold DB 参考结构核心区 Cα-RMSD 为 0.31 埃。

5. 诚实工程，把失败也做成可验证的证据。T1024 三次公网运行均未完成，基准页如实显示"待运行"，不粉饰、不重试赌博。根因查得很干净：前两次死于两处分层超时缺陷（worker HTTP 服务默认 300 秒请求超时、客户端默认 300 秒头部超时，且错误被降级提示掩盖，极易误判为缺少 API key），两处均已定位修复并顺带修正了发布链路；第三次在修复全部生效后被团队保留的单任务 20 分钟保护上限终止，真瓶颈是长链折叠依赖的公共 MSA 服务排队时长不可控（同日实测 14 分钟与超过 20 分钟两档，而 GPU 推理本身仅约 2 分钟），worker 侧留有同日完整折叠产物（pTM 0.78、pLDDT 0.905）为证。团队按设计取舍不放宽上限，三次会话日志与修复提交链公开可溯。

6. 结果验证具有独立性：基准打分在服务端完成，不依赖前端、不依赖页面在线。

7. 可复现：仓库内附探针套件，覆盖归档装配 13 项、预测流全生命周期 42 项、Cα-lDDT 打分数学 22 项，共 77 项单元断言，另有公网端到端探针；typecheck 与 lint 门禁干净，文中关键分数与复现命令一一对应，可供现场抽查。
