## 一、AI 辅助开发披露

本作品在开发过程中使用了 AI 编程助手辅助编写代码、排查缺陷与撰写文档，所用模型为 GLM-5.3-Flash。所有 AI 产出均经团队成员逐项审查、测试与整合后方纳入作品；系统设计决策、架构方案与最终验证由团队完成。相关提交在版本库中带有 `Co-Authored-By: Claude Code` 标记，完整的开发与审查过程可通过 git 历史追溯。团队确认该使用方式符合竞赛关于 AI 使用的规定。

## 二、第三方素材与数据来源披露

1. 智能体底座。本作品使用竞赛指定的智能体运行与执行底座 Agnes Harness（AGH），按竞赛要求使用，未修改其许可证文本。

2. 开源软件（均按其许可证使用）。boltz_community 2.10.12（MIT，本地结构与复合物预测推理，自备权重）；Caddy 2.10.2（Apache-2.0，服务器反向代理与登录门）；Node.js（MIT，运行时）；另使用开发工具链 biome、TypeScript、tsx、vitest 等（各自宽松许可，仅开发期使用，不随作品分发）。本作品自研业务包（protein-platform / protein-predictor / protein-view）运行时零 npm 依赖，未捆绑任何第三方 npm 包。

3. 外部数据与预测服务（按各自条款合法调用）。UniProt REST API（CC BY 4.0，按 ID 检索蛋白序列）；ESMFold 折叠端点（CC BY 4.0，© Meta；服务条款要求非批量、不得过度使用，本作品以单条序列逐次调用，未做批量折叠）；AlphaFold DB 预测结构文件（CC BY 4.0，© DeepMind / EMBL-EBI，单体结果的对比参考，按 ID 按需获取）；RCSB PDB 实验结构（CC0 1.0，平台基准页的参考答案）；Boltz-2 托管 API（按服务条款自购密钥，算力路由第二档，密钥由团队持有，不随作品分发）。

4. 图片、字体与 3D 资产。无。平台界面的 3D 渲染（结构、热图、缩略图）全部由本项目自有代码实时生成（Canvas / WebGL），未使用任何第三方图片、字体或 3D 模型资产。

5. 引用的学术方法。pLDDT / PAE 置信度口径与 Cα-lDDT 打分（Mariani et al., *Bioinformatics*, 2013）；Boltz-2（Passaro, Corso, Wohlwend et al., *Boltz-2: Towards Accurate and Efficient Binding Affinity Prediction*, bioRxiv 2025，MIT 开源实现及论文）；ESMFold（Lin et al., *Science*, 2023）。仅在文档与结果标注中引用其方法与口径，未复制其代码或数据。
