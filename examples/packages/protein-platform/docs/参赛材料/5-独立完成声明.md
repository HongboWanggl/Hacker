### 1. AI 辅助开发披露

本作品在开发过程中使用了 AI 编程助手（Claude Code / GLM，Anthropic 与 Z.ai 的模型）辅助编写代码、排查缺陷与撰写文档。所有 AI 产出均经团队成员逐项审查、测试与整合后方纳入作品；系统设计决策、架构方案与最终验证由团队完成。每一条相关提交在版本库中均带有 `Co-Authored-By: Claude Code` 标记，完整的开发与审查过程可通过 git 历史追溯。团队确认该使用方式符合竞赛关于 AI 使用的规定。

- **Agnes Harness（AGH）**：竞赛指定的智能体运行与执行底座，按竞赛要求使用。

**无**。平台界面的 3D 渲染（结构、热图、缩略图）全部由本项目自有代码实时生成（Canvas/WebGL），未使用任何第三方图片、字体或 3D 模型资产。
