# 运行与验证证据

> 四部分：AGH 执行记录说明、探针清单（可复现命令）、CASP14 基准实测分数、正常/边界/失败三类测试样例。

## 一、AGH 执行记录

- **会话级记录**：平台每个任务对应一个 AGH agent 会话（`sdk.session.new({ cwd, preset: 'standard' })` 创建，`orchestrator.ts:381`）。AGH 将会话事件（提示词、工具开启/结果、异常）写入会话日志；断线重连走 `sdk.session.load` 回放（`orchestrator.ts:538`），归档的任务元数据中保存了 `sessionId` 可回溯对应会话。
- **工具调用过程**：agent 的每次工具调用（`predict_structure` / `predict_complex` / `batch_predict` / `uniprot_search` / `compare_with_alphafold`）在会话事件流中留有完整的开启与结果事件；前端进度页即对该事件流做账本归约实时呈现（工具开启 → 阶段点亮）。
- **平台侧记录**：VPS 上 daemon 运行日志 + Caddy 访问日志 + 平台归档（`archive/` 目录，含 report.json / model.pdb / pae.json / 预生成缩略图），三者时间戳可交叉印证一次真实预测的发生。
- **导出方式**：提交材料时随附 2–3 个代表性任务的归档 JSON + 对应会话日志摘录（涉及凭据/密钥的字段已剔除）。

## 四、三类测试样例

### 正常样例

1. **单体 · `P69905`（血红蛋白 α，141 aa）**：ESMFold 预测成功，平均 pLDDT 94.7；`compare_with_alphafold` 与 AlphaFold DB 参考结构（AF-P69905-F1 v6）Horn 叠合后，核心区 Cα-RMSD **0.31 Å**（141 个双方 pLDDT≥70 的残基；全残基 0.34 Å），判定「与参考高度一致」。归档 taskId `tmv7ue2s0ujd8`，报告含逐残基 ΔpLDDT 序列可复核。
2. **复合物 · 双链 + 阿司匹林 SMILES**：Boltz-2 产出多链 PDB + PAE 热图，ipTM 评分与配体结合概率正常呈现。
3. **归档往返**：任务完成后换浏览器/设备打开「全部任务」，结果页完整重建（服务端归档，不依赖页面在线）。

### 边界样例

1. **长度边界 · 长链单体**：`predict_structure` 工具对 >1000 aa 直接拒绝；约 400 aa 以上送达公共 ESMFold 端点被拒（HTTP 413）时，失败信息明确指路 `predict_complex`，agent 会话随即按提示改走 Boltz-2 长链档（T1024 的会话日志记录了完整的 413 → 换档切换链路；400+ aa 长链回退分支由 `boltz-flow-unit.mts` 的降级断言覆盖）。
2. **批量上限 · >8 个 UniProt ID**：输入框黄条提示「最多 8 个，仅取前 8 个」，服务端归档同样只处理前 8 个（`composer.ts` 的 `analyzeInput` 与 `archive.ts` 双侧一致）——截断显式可见，绝不静默丢弃。
3. **超长 PAE 矩阵 · >800 残基**：超过 1 MiB 结果预算时按块 mean-pool（`scale = ⌈n/800⌉`），热图仍可用且标注 scale（`protein-view/extensions/main/index.mjs` 的 `protein.pae` 分支）。
4. **归档超预算 · 大 PDB**：`pdb-*` 按体积从大到小丢弃、report.json 必存活（archive-put.mts「over budget」用例）。
5. **路径安全 · `../../etc/passwd`**：穿越路径解析为空，归档不含 report/pdb（archive-put.mts 路径穿越用例）。

### 失败样例

1. **真实失败记录 · CASP14 T1024（408 aa 膜蛋白）**：三次公网运行均未完成，基准页如实显示「待运行」，不粉饰。前两次（2026-10-14）死于两处分层超时缺陷——worker HTTP 服务默认 300s 请求超时、客户端 fetch 默认 300s 头部超时；长链折叠经常超过 5 分钟，响应被提前掐断且被降级提示掩盖——均已定位修复（commit 41ace5e、123a214，并修正了包发布链路：须发布到 profile 安装快照而非仅改源码树）。第三次全部修复生效后被保护性单任务 20 分钟上限终止：瓶颈是 Boltz 长链折叠依赖的公共 MSA 服务排队时长不可控（当日实测 14 min 与 >20 min 两档；GPU 推理本身约 2 min，worker 侧留有同日完整折叠产物 pTM 0.78 / pLDDT 0.905 为证）。按设计取舍不放宽上限，如实保留失败记录（三次会话日志与 commit 链可溯）。
2. **鉴权失败回退 · 401**：托管 API bearer 失败自动换 `x-api-key` 头重试（boltz-flow-unit 断言）。
3. **任务失败呈现与恢复**：失败原因行如实展示 +「↻ 重新提交」原样重跑；运行中可两键取消。
4. **瞬时抖动**：网关超时/限流/连接中断自动重试最多两次（操作手册 §4 对用户公示的行为）。
5. **worker 缺席**：GPU worker 探活 1.5 s 失败 → 静默落回 API/本地档，任务照常完成（boltz-flow-unit 的死端口注入即模拟此场景）。

每条失败样例均有对应自动化断言或可现场复现的公网操作，与《演示视频》分镜 5/6 对应。
