# 运行与验证证据

> 三部分：AGH 执行记录说明、探针清单（可复现命令）、正常/边界/失败三类测试样例。

## 一、AGH 执行记录

- **会话级记录**：平台每个任务对应一个 AGH agent 会话（`sdk.session.new({ cwd, preset: 'standard' })` 创建，`orchestrator.ts:381`）。AGH 将会话事件（提示词、工具开启/结果、异常）写入会话日志；断线重连走 `sdk.session.load` 回放（`orchestrator.ts:538`），归档的任务元数据中保存了 `sessionId` 可回溯对应会话。
- **工具调用过程**：agent 的每次工具调用（`predict_structure` / `predict_complex` / `batch_predict` / `uniprot_search` / `compare_with_alphafold`）在会话事件流中留有完整的开启与结果事件；前端进度页即对该事件流做账本归约实时呈现（工具开启 → 阶段点亮）。
- **平台侧记录**：VPS 上 daemon 运行日志 + Caddy 访问日志 + 平台归档（`archive/` 目录，含 report.json / model.pdb / pae.json / 预生成缩略图），三者时间戳可交叉印证一次真实预测的发生。
- **导出方式**：提交材料时随附 2–3 个代表性任务的归档 JSON + 对应会话日志摘录（涉及凭据/密钥的字段已剔除）。

## 三、三类测试样例

### 正常样例

1. **单体 · `P69905`（血红蛋白 α，141 aa）**：ESMFold 预测成功，平均 pLDDT ≈ 90+，与 AlphaFold DB 参考对比核心区 Cα-RMSD < 2 Å「与参考高度一致」。
2. **复合物 · 双链 + 阿司匹林 SMILES**：Boltz-2 产出多链 PDB + PAE 热图，ipTM 评分与配体结合概率正常呈现。
3. **归档往返**：任务完成后换浏览器/设备打开「全部任务」，结果页完整重建（服务端归档，不依赖页面在线）。

### 边界样例

1. **长度边界 · 400+ aa 长链**：ESMFold 端点对超长序列拒绝 → 自动落回 Boltz-2 档完成预测（回退分支由 `boltz-flow-unit.mts` 的降级断言覆盖）。
2. **批量上限 · >8 个 UniProt ID**：第 9 个起被拒绝并黄条提示，平台不静默截断。
3. **超长 PAE 矩阵 · >800 残基**：超过 1 MiB 结果预算时按块 mean-pool，热图仍可用且标注 scale（`extensions/main/index.mjs` 的 `protein.pae` 分支）。
4. **归档超预算 · 大 PDB**：`pdb-*` 按体积从大到小丢弃、report.json 必存活（archive-put.mts 断言 4）。
5. **路径安全 · `../../etc/passwd`**：穿越路径解析为空，归档不含 report/pdb（断言 2）。

### 失败样例

1. **确定性失败 · CASP14 T1024（408 aa 膜蛋白）**：各档均无法完成 → 基准页如实显示「待运行」，不粉饰。
2. **鉴权失败回退 · 401**：托管 API bearer 失败自动换 `x-api-key` 头重试（boltz-flow-unit 断言）。
3. **任务失败呈现与恢复**：失败原因行如实展示 +「↻ 重新提交」原样重跑；运行中可两键取消。
4. **瞬时抖动**：网关超时/限流/连接中断自动重试最多两次（操作手册 §4 对用户公示的行为）。
5. **worker 缺席**：GPU worker 探活 1.5 s 失败 → 静默落回 API/本地档，任务照常完成（boltz-flow-unit 的死端口注入即模拟此场景）。

每条失败样例均有对应自动化断言或可现场复现的公网操作，与《演示视频》分镜 5/6 对应。
