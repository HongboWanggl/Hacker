**标题（选一）**

- 把 AlphaFold 做成浏览器里的智能体工作台：一个本科生项目的 CASP14 实测记录
- 不会写代码也能预测蛋白质结构：我们在 Agnes Harness 上搭了一个平台

**正文**

蛋白质结构预测这两年进展飞快，但对非生物信息学的同学来说，真正的门槛从来不是"有没有工具"，而是三件事：命令行和 GPU 环境、多个工具的手动拼装、以及最难的一点——**拿到一个 PDB 文件，你怎么知道它可不可信？**

我们（南京大学，本科生）在 Agnes Harness 上搭了一个平台，把这三件事合成一个浏览器页面：输入 UniProt ID、原始序列或 FASTA，平台自动开一个智能体会话，由会话里的模型自己规划调用哪个预测工具（短链走 ESMFold、复合物和长链走 Boltz-2），经三级算力路由（自建 RTX 4060 → 托管 API → 本地开源权重）完成折叠，最后给出带完整置信度体系的结果——逐残基 pLDDT 着色、置信度曲线、分段统计，复合物还有 ipTM 和 PAE 热图。

**平台自身接受学术基准检验。** 我们选了 CASP14 的公开靶标集跑真实管线，用 RCSB 实验结构做真值，服务端独立计算 Cα-lDDT 和 Cα-RMSD，并把模型自报的 pLDDT 与实测值做成校准直方图公开对照。九个靶标完成自动打分：最好的一靶 T1025 达到 lDDT 0.952 / RMSD 0.65 Å，四靶超过 0.8；分数低的那几靶（0.29–0.47）我们也如实呈现——单序列从头预测的难度是真实存在的，不挑分数、不修饰。

一个诚实的记录：408 aa 的膜蛋白 T1024 在我们的公网环境三次都没跑完，原因最后定位为该链路依赖的公共 MSA 服务排队时间不可控（当天实测 14 分钟到 20 分钟以上两档），而我们对单任务设了 20 分钟的硬上限。三次失败的会话日志、每一次的根因和修复 commit 都在——这可能是这个项目里我们最愿意拿出来讲的工程部分。

代码与运行说明在 GitHub，公网平台可以直接体验（链接见评论区/主页）。欢迎拍砖。

**要点（供剪短版/摘要用）**

- 三种输入、三种任务一键提交；结果自带可判读的置信度体系
- 三级算力路由，GPU worker 缺席自动降级，用户无感
- CASP14 公网实测：最高 lDDT 0.952 / RMSD 0.65 Å；置信度校准实测一致；独立对照 P69905 对 AlphaFold DB 核心区 0.31 Å
