**标题（选一）**

- ProteinLens 蛋白透镜：把蛋白质结构预测做进浏览器，还能告诉你结果可不可信
- 不会写代码也能预测蛋白质结构：我们在 Agnes Harness 上搭了一个平台（CASP14 实测记录）

**正文**

蛋白质结构预测这两年进展飞快，但对非生物信息学的同学来说，真正的门槛从来不是"有没有工具"，而是三件事：命令行和 GPU 环境、多个工具的手动拼装、以及最难的一点——**拿到一个 PDB 文件，你怎么知道它可不可信？**

我们（南京大学，本科生）在 Agnes Harness 上搭了一个平台，叫 **ProteinLens 蛋白透镜**（透镜 = 让你看穿一次预测到底可不可信），把这三件事合成一个浏览器页面：输入 UniProt ID、原始序列或 FASTA，平台自动开一个智能体会话，由会话里的模型自己规划调用哪个预测工具（短链走 ESMFold、复合物和长链走 Boltz-2），经三级算力路由（自建 RTX 4060 → 托管 API → 本地开源权重）完成折叠，最后给出带完整置信度体系的结果——逐残基 pLDDT 着色、置信度曲线、分段统计，复合物还有 ipTM 和 PAE 热图。

**平台经过学术基准检验。** 我们选了 CASP14 的公开靶标集跑真实管线，用 RCSB 实验结构做真值，服务端独立计算 Cα-lDDT 和 Cα-RMSD，并把模型自报的 pLDDT 与实测值做成校准直方图对照。四个靶标达到 lDDT ≥ 0.8：最好的一靶 T1025 达到 lDDT 0.952 / 全残基 RMSD 0.65 Å，另有 T1030 0.943、T1046s2 0.859、T1056 0.817。

代码与运行说明在 GitHub，公网平台可以直接体验（链接见评论区/主页）。欢迎拍砖。

**要点（供剪短版/摘要用）**

- 三种输入、三种任务一键提交；结果自带可判读的置信度体系
- 三级算力路由，GPU worker 缺席自动降级，用户无感
- CASP14 公网实测：最高 lDDT 0.952 / RMSD 0.65 Å；置信度校准实测一致；独立对照 P69905 对 AlphaFold DB 核心区 0.31 Å
- 77 项单元断言 + 公网端到端探针，全部可复现
