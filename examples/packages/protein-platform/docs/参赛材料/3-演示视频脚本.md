## 镜头 1｜任务输入与反馈调整（0:22–1:12）

**操作**（全部在首页输入框完成，鼠标指着输入框下方）

1. 清空输入框，粘贴 UniProt ID `P69905` → **停 1.5 秒**给识别 chip 特写。
2. 全选删除，粘贴 141 aa 原始序列 → 停 1.5 秒。
3. 在序列末尾**故意敲两个数字**（如 `12`）→ 黄条警告出现 → 停 1.5 秒 → **删掉数字**，chip 恢复。
4. 全选删除，粘贴 FASTA（`>sp|P69905|HBA_HUMAN …` + 序列）→ 停 1.5 秒。
5. 切到「批量」页签，粘贴 **10 个** UniProt ID → 黄条出现 → 删掉 2 个，chip 变为 8 个。
6. 切回「单体」页签，鼠标依次悬停「复合物」「批量」两个页签各 1 秒（展示页签占位提示），最后停在「单体」。

**预期画面**（输入框下方的实时识别 chip，逐字如下）

| 输入 | chip 文案 |
|---|---|
| `P69905` | `UniProt ID · P69905` |
| 141 aa 序列 | `原始序列 · 141 aa` |
| 序列混入数字 | `⚠ 含数字或特殊字符，无法识别为序列`（黄色） |
| 删掉数字后 | 恢复 `原始序列 · 141 aa` |
| FASTA | `FASTA · 141 aa` |
| 10 个 ID（批量页） | `10 个 UniProt ID` + `⚠ 最多 8 个，仅取前 8 个` |
| 删到 8 个 | `8 个 UniProt ID` |

- 复合物页签悬停时，输入框占位提示变为「每行一条链序列（按 A、B、C… 顺序）」；下方出现 **配体 SMILES（可选）** 输入框。
- 批量页签占位提示为「每行一个 UniProt ID（≤8 个）」。
- 首页大标题 **「蛋白质结构预测，从此只需粘贴」**。

**旁白**
> 「三种输入方式：UniProt ID、原始序列、FASTA，也支持一句话描述。输入框会实时告诉用户它读到了什么、会丢掉什么——序列里混进数字，立刻黄条警告；批量粘了十个，明确提示只取前八个。用户在看到警告的当场就能改，不用等提交失败。」

**剪辑提示**：第 3、5 步的「警告出现→删除→恢复」是**反馈调整**的正面示范，务必保留完整操作，不要跳剪。

## 镜头 2｜提交与执行过程（1:12–1:58）

**操作**
1. 输入框保持 `P69905`，点 **「开始预测 →」**（或 ⌘/Ctrl+Enter）。

3. **关键动作**：进度条走到「结构预测」时，**直接关掉这个标签页**；等 3 秒，从顶栏「任务」页重新点开同一任务。
4. 任务已完成，结果页直接呈现。

**预期画面**

## 镜头 3｜结果呈现与判读（1:58–2:52）

**操作**（用刚完成的 P69905 结果页）

1. 3D 结构区：按住拖拽旋转一周，滚轮放大一次 → 指出颜色分段（深蓝→浅蓝→黄→橙）。
2. 置信度曲线：鼠标悬停曲线中段某残基 → 3D 上对应残基**联动高亮** → 沿曲线横扫一段。
3. 序列条：按住拖选一个区段（约 30 个残基）→ 展示区段统计。
4. 指出「分段统计」卡片：连续低置信区段被自动列出。
5. 切到顶栏「任务」→ 点开**预跑的复合物任务** → 展示 ipTM / pTM 数值与 PAE 热图，鼠标扫过几个热图块。
6. 顶栏「任务」页：展示类型筛选 chips（单体/复合物/批量）与搜索框输入 `HBA` 的过滤效果。

**预期画面**
- 结果页顶部：任务名（如 `P69905`）、**平均 pLDDT** 数值、判定徽标（如「高置信结构」）。
- 3D 结构可交互旋转/缩放，按 pLDDT 逐残基着色；图例色标：**≥90 很高（深蓝）· 70–90 高（浅蓝）· 50–70 中（黄）· <50 低（橙）**。
- 置信度曲线悬停时 3D 对应位置高亮；序列条可拖选区段。
- 「分段统计」卡片列出连续低置信区段的起止残基。
- 复合物结果页：**ipTM**（链间置信度）、**pTM**、配体结合概率，以及 **PAE 误差热图**（0–32 Å 色标）。
- 任务页徽标：运行中 / 已完成 / 已取消；筛选 chips 可按类型过滤。

**旁白**
> 「结果不只是一个 PDB 文件。三维结构按 pLDDT 逐残基着色，蓝色可信、红色要当心；悬停置信度曲线上任何一个残基，三维里对应位置立刻高亮；哪一段连续不可信，平台自动列出来。复合物额外给出链间置信度 ipTM 和 PAE 误差热图——界面上结合得稳不稳，一眼能看出来。所有历史任务都能按类型筛选、按分数排序，跨设备重新打开。」

**剪辑提示**：复合物任务用预跑归档，不现场等；3D 旋转保留完整手势，不要加速（体现真实交互）。

## 镜头 4｜外部能力调用（2:52–3:30）

**操作**
1. 回到 P69905 单体结果页，点 **「⇄ 与 AlphaFold DB（P69905）对比 →」** → 等结论出现，指出核心区 RMSD 数值与判定语。
2. 顶栏切「检索」页，输入 `hemoglobin human` → 点 **「检索 →」** → 候选表出现在下方，鼠标扫过 accession / 物种 / 长度三列 → 点某一行行尾的 **▶**（预测该条）。
3. （可选，10 秒）切「指南」页停留 2 秒，展示三级算力路由与使用说明。

**预期画面**
- 对比完成后出现结论卡：核心区 Cα-RMSD 数值（P69905 实测约 **0.3 Å**）+ 判定 **「与参考高度一致」**；逐段差值可查。
- 检索页标题 **「UniProt 检索」**，副标题「按蛋白名称 / 关键词检索 UniProt，候选表可直接查看 accession、物种与长度」；输入框占位提示「如：hemoglobin human / p53 / kinase SARS-CoV-2」。
- 候选表每行：蛋白名、accession、物种、长度，行尾 **▶** 按钮；表格下方提示「点候选行尾 ▶ 或勾选后批量预测，任务会出现在任务页；**检索本身不留记录**」。
- 点 ▶ 后新任务进入「任务」页，状态「运行中」。

**旁白**
> 「平台按需调用外部能力：拿自己的预测和 AlphaFold DB 的参考结构叠合算 RMSD，血红蛋白 α 的核心区只有 0.3 埃，说明折叠结果可信；也可以在 UniProt 里按名字检索，看中哪条直接一键预测。背后预测请求在三级算力之间自动路由和降级——自建 GPU、托管 API、本地开源权重，哪一档不可用就静默落到下一档，用户侧完全无感。」

**剪辑提示**：英文关键词 `hemoglobin human` 走 UniProt 直查、候选秒出；若现场网络慢，改用预跑的检索结果页录制。点 ▶ 产生的新任务**不必等它跑完**，切到任务页看到「运行中」即可切走。

## 镜头 6｜异常处理与分享（4:02–4:32）

**操作**
1. 顶栏「任务」→ 点开**预跑的失败任务** → 指着失败原因行读一句 → 点 **「↻ 重新提交此任务」**。
2. 回到运行中的任务页，点右上 **「取消」** → 按钮变红 **「确认取消」** → 再点一次 → 徽标变 **「已取消」**。
3. 回到 P69905 结果页，点 **「⇩ 分享报告（HTML）」** → 下载完成 → 切到桌面双击打开 → 拖拽旋转 3D 一次。
4. （如录了取消）指出「已取消」与「失败」徽标视觉上的区分。

**预期画面**
- 失败任务页：红色错误横幅写明失败原因（如公共折叠服务返回 HTTP 413 / 请求超时），下方按钮 **「↻ 重新提交此任务」**（点击时变「重新提交中…」）。
- 取消：按钮文案 **「取消」** → 悬停/点击后变红 **「确认取消」**（4 秒内需二次确认，防误触）→ 徽标变 **「已取消」**。
- 分享报告：按钮变「生成报告中…」→ 浏览器下载一个 HTML 文件（约 12 万字节）→ 双击打开为自包含页面，标题 `<任务名> · ProteinLens 蛋白透镜报告`，内含 pLDDT 评分、结构与曲线快照、**可拖拽旋转的 3D 视图**，离线可用。
- 报告页脚有色标说明：「pLDDT 置信度色标：≥90 很高（深蓝）· 70–90 高（浅蓝）· 50–70 中（黄）· <50 低（橙）」。

**旁白**
> 「失败也不藏着：失败原因明确写出来，一键按原输入重跑；运行中随时可以两键取消，取消和失败是两种不同的状态，不会混为一谈。最后，任何结果都能导出一份自包含的交互式报告——没有网络、没有平台，也能打开、也能转着看，直接发给同事就行。」

**剪辑提示**：失败任务用预跑素材（见准备项 3③）；「重新提交」点下去看到状态变化即可切走，不必等它跑完。
