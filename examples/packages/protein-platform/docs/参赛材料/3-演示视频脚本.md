# 演示视频分镜脚本（3–5 分钟）

> 要求覆盖全流程：任务输入 → 执行过程 → 外部能力调用 → 反馈调整 → 结果验证 → 异常处理。
> 以**实际操作录屏为主**，旁白词已写好，照读即可。【】内为待定细节。
> 录制前准备：登录 guest 账号；提前跑好并保留两个历史任务（一个单体、一个复合物）作为"归档/分享"环节素材，避免现场等待。

## 分镜 1｜任务输入（0:00–0:45）

**操作**：
1. 打开平台首页，登录框输入 guest 账号（密码打码或后期遮盖）。
2. 粘贴 UniProt ID `P69905` → 指着输入框下方实时识别「UniProt ID · P69905」。
3. 换成原始序列粘贴 → 识别变「原始序列 · 141 aa」；故意在序列里混入数字 → 黄条警告出现再删掉。
4. 粘贴 FASTA → 识别「FASTA · 141 aa」。
5. 切换三个任务页签（单体 / 复合物 / 批量）各停 1 秒，复合物页签展示两行序列 + 阿司匹林 SMILES 示例，批量页签展示多行 UniProt ID。

**旁白**：平台支持三种输入方式——UniProt ID、原始序列和 FASTA，输入框会实时识别类型并给出长度和格式警告。支持三种任务：单体预测、复合物预测（可加配体）、批量预测。

## 分镜 2｜提交与执行过程（0:45–1:45）

**操作**：
1. 用 `P69905` 提交**单体预测**（⌘/Ctrl+Enter）。
2. 结果页展示阶段进度「取序列 → 折叠预测 → 置信度分析」，鼠标跟随阶段流转；指出阶段点亮的实时反馈。
3. **中途关闭标签页再重开**：从「全部任务」点开该任务 → 进度继续、结果照常出现（关键卖点：会话在 AGH 服务端持续运行，页面只是观察窗口）。

**旁白**：提交后每个任务由一个 Agnes Harness 智能体会话接管，页面实时回放会话事件流。注意执行中可以直接关掉页面——会话在服务端继续跑，重开页面进度和结果都还在。

## 分镜 3｜结果呈现（1:45–2:45）

**操作**（用刚完成的 P69905 结果页）：
1. 3D 结构拖拽旋转、滚轮缩放；指出 pLDDT 着色（蓝=高置信 → 红=低置信）。
2. 置信度曲线：鼠标悬停曲线某残基，3D 上对应位置联动高亮；序列条拖选一个区段。
3. 指出分段统计卡（连续低置信区段）。
4. 切到预先跑好的**复合物**结果：展示 ipTM 评分与 PAE 热图，鼠标扫过热图块。
5. 顶栏「全部任务」展示类型筛选 chips + 搜索；首页报告墙切「最高分」排序。

**旁白**：结果不只是结构文件——pLDDT 着色、置信度曲线、分段统计让非专业用户一眼判断可信度；复合物额外给出链间置信度 ipTM 和 PAE 误差热图。历史任务在报告墙可按分数排序、跨设备重新打开。

## 分镜 4｜外部能力调用（2:45–3:30）

**操作**：
1. 结果页点「⇄ 与 AlphaFold DB 对比」→ 展示 RMSD 对齐结论（核心区 < 2 Å「与参考高度一致」）。
2. 打开顶栏「检索」页搜 `hemoglobin` → 行内 ▶ 一键预测 / 勾选多条「预测所选」。
3. 快切一张架构示意（可提前做好一张图）讲三级算力路由：GPU worker → 托管 API → 本地权重，任一级失败自动降级。

**旁白**：平台按需调用外部能力——AlphaFold DB 参考结构做对比验证、UniProt 检索取序列、ESMFold/Boltz-2 做折叠。预测请求在三个算力档之间自动路由与降级，对用户完全透明。

## 分镜 5｜结果验证：基准页（3:30–4:10）

**操作**：打开顶栏「基准」页：
1. CASP14 十靶标打分表（Cα-lDDT / Cα-RMSD 列）。
2. pLDDT 校准直方图，指出柱子贴近对角线 = 模型置信度诚实。
3. **特别指出 T1024 显示「待运行」**——平台如实呈现失败，不粉饰。

**旁白**：平台自身接受公开学术基准 CASP14 的检验：十个真实竞赛靶标与实验解析结构对比打分。这个直方图检验模型置信度是否诚实。而这一个显示"待运行"的靶标是真实失败——平台如实呈现。

## 分镜 6｜反馈调整与异常处理（4:10–4:50）

**操作**：
1. 对已完成的任务点「⇩ 分享报告」→ 下载 HTML → 打开：收件人可拖拽旋转的交互式 3D 报告。
2. 演示失败处理：选一个失败任务页（可提前准备一个故意失败的任务，如超长序列 ESMFold 拒绝），指出失败原因行 → 点「↻ 重新提交」。
3. （可选）演示运行中两键取消：点「取消」→「确认取消」。

**旁白**：偶发的服务抖动平台自动重试最多两次；仍失败时失败原因如实展示，可一键原样重跑。运行中也可以随时两键取消。最后，任何结果都能生成一个自包含的交互式报告分享给别人。

**结尾（4:50–5:00）**：回到首页报告墙定格。旁白：从输入到可信、可验证、可分享的结构预测结果，浏览器打开即用。

### 录制注意事项

- 浏览器窗口 1920×1080 以上，字体缩放 100%；录屏 30fps 起。
- guest 登录密码用后期遮盖，不要现场输入真实密码后不处理。
- 等待类镜头（预测进行中）用剪辑跳剪，只保留阶段流转关键画面；每段等待不超 10 秒。
- 分镜 2 的"关页面再重开"和分镜 6 的"失败重试"是差异化亮点，务必保留完整操作。
