**项目摘要**（约 200 字）

```
本项目是双层定位的作品：它既是一个即开即用的蛋白质结构预测前端（面向零生信背景用户，
浏览器打开即可用），也是一个运行在 Agnes Harness 上的科研助手——以一个完整科研工作流
（任务规划 → 工具编排 → 结果验证 → 外部基准检验）验证通用智能体底座承接专业科学任务的能力。

面向零生物信息学背景的用户，把"蛋白质结构预测"从命令行工具变成浏览器即开即用的智能体工作台。
用户只需输入 UniProt ID、原始序列、FASTA 或一句自然语言描述（如「人类血红蛋白 α 链」，
候选表当场列在输入框下方，选中即预测——检索这一步不建任务、不留记录），平台即在 Agnes Harness 上
开启一个 agent 会话，由会话内的 Agnes 模型自主规划并调用预测工具（ESMFold 单体 / Boltz-2 复合物与长链），
经三级算力路由（自建 GPU worker → 托管 API → 本地开源权重）完成折叠。
每个结果自带完整置信度体系（pLDDT 逐残基着色、置信度曲线、分段统计、复合物 ipTM 与 PAE 热图），
让非专业用户也能判断"这次预测可不可信"。平台自身接受外部学术基准检验：CASP14 公开靶集在公网
真实管线完成自动打分（Cα-lDDT / Cα-RMSD，RCSB 实验结构为真值），并公开 pLDDT 校准直方图。
```

**亮点特色**（≤50 字，48 字符含空格）

```
即开即用前端+Agnes Harness 科研助手：置信度可判读，CASP14 最高 0.952
```

**问题来源与目标**

```
问题来源：蛋白质结构预测工具（AlphaFold、ColabFold、Boltz-2 等）对非生物信息学用户门槛很高——
需要命令行、Python/GPU 环境、多工具手动拼装；更关键的是，产出一个 PDB 文件不等于可用：
预测质量参差，而普通用户缺乏判断"这次预测可不可信"的能力。

项目目标：
1. 四种输入（UniProt ID / 原始序列 / FASTA / 一句话自然语言描述）实时识别，三种任务（单体预测、复合物预测、批量预测）一键提交；描述类输入由平台就地列出候选（直查 UniProt，中文描述自动经一次 agent 回合翻检索式），选中即预测；
2. 每个结果自带置信度体系（pLDDT 着色、置信度曲线、分段统计、复合物 ipTM 与 PAE 热图），让非专业用户能判断可信度；
3. 平台自身接受外部学术基准检验（CASP14 靶集，Cα-lDDT / Cα-RMSD 打分 + pLDDT 校准直方图）；
4. 历史归档、对比分析、可分享的自包含 HTML 报告。
```

## 二、技术信息

**AGH 作用**（Agnes Harness 在本项目中的角色）

```
AGH 是本平台的智能体执行底座，不是可选组件：每个预测任务 = 一个 AGH agent 会话
（sdk.session.new({ cwd, preset: 'standard' })，orchestrator.ts:381）。
- 能力注册：预测与查询能力经 agnes.registerTool（predict_structure / predict_complex /
  batch_predict / uniprot_search / compare_with_alphafold）与 ctx.services.register
  （protein.structure / protein.report / protein.pae / protein.file）注册，由会话内 agent 规划调用；
- 过程可观测：平台对 session.events() 做账本式归约（工具开启/结果关闭成对事件）实时驱动进度页；
- 断线可恢复：页面关闭/刷新后经 sdk.session.load（orchestrator.ts:538）重连并回放事件日志，
  任务不丢、进度真实；
- 结果可验证：任务完成后由服务器拉取工作区产物归档，「基准」页以 RCSB 实验结构为真值独立打分。
```

**Agnes 模型名称 / 版本 / 使用环节 / 调用方式**

| 项 | 内容 |
| --- | --- |
| 名称与版本 | **Agnes 3.0 Flash**（模型 ID `agnes-3.0-flash`，主档 slot: primary） |
| 使用环节 | 每个任务会话的**规划与工具调用决策**：识别输入类型、决定调用哪个预测工具、读取工具失败信息后换档重试、汇总结果成报告。CASP14 靶集、单体/复合物/批量全部任务均由该模型会话驱动 |
| 调用方式 | 经 **Agnes AI 网关**（`https://api.agnes-ai.cn/v1`，OpenAI-compatible 协议）调用；原生工具调用（toolCallFormats: native），200K 上下文、单次最大 65536 tokens，思考链回放策略 drop |
| 配置位置 | VPS 平台 profile 的 `profile.yaml` 自有路由（`route: agnes-ai`），凭据存于 `data/secrets`，不进代码仓库 |
| 备用路由 | 网关抖动时由 **Doubao Seed 2.0 Pro**（`doubao-seed-2-0-pro-260215`，火山方舟 agent-plan 端点，Anthropic messages 协议，256K 上下文）接管，对上层透明 |
| 使用证据 | 平台会话库 `sessions.db` 中 `agnes-3.0-flash` 出现 **265 处**、备用模型 0 处——全部平台会话（含 CASP14 靶标的公网运行）均由 Agnes 3.0 Flash 驱动；每个任务的会话事件流中可看到该模型发起的工具调用事件（开启→结果成对） |

**数据 / 代码 / 专业软件 / 仿真环境 / API / 设备接口**

```
数据：UniProt（序列查询）、RCSB PDB（实验结构真值）、AlphaFold DB（参考预测结构，CC BY 4.0）、
      CASP14 公开靶标序列（targets.json）
```
