## 2. 首页：三种输入方式

粘贴任意一种，输入框下方会**实时显示识别结果**（如「原始序列 · 147 aa」「UniProt ID · P69905」「FASTA · 141 aa」），黄条代表有内容会被忽略：

| 输入 | 示例 | 说明 |
| --- | --- | --- |
| UniProt ID | `P69905` | 自动取该蛋白序列（支持突变体后缀如 `P69905-2`） |
| 原始序列 | `MVLSPADKTNVKAAWGKVGAHAGEYGAEAL…` | 纯氨基酸字母，≥10 个；含数字会黄条警告 |
| FASTA | `>sp\|P69905\|HBA_HUMAN\nMVLSPA…` | 多条记录时**只取第一条**（黄条提示其余被忽略） |

⌘/Ctrl + Enter 可直接提交。

## 3. 三种任务类型（输入框下方的切换页签）

| 类型 | 输入格式 | 产出 |
| --- | --- | --- |
| **单体结构预测** | 上表任一方式，一条序列 | 3D 结构 + pLDDT 置信度报告（约 1–4 分钟） |
| **复合物预测** | 每行一条链序列（≥5 aa），可选填配体 SMILES（如阿司匹林 `CC(=O)OC1=CC=CC=C1C(=O)O`） | 多链复合物 + 界面置信度（ipTM）+ PAE 误差热图（Boltz-2，约 3–8 分钟） |
| **批量预测** | 每行一个 UniProt ID（最多 8 个） | 逐目标结果汇总卡，每行可展开 3D 详情（约 3–10 分钟） |

## 4. 任务提交后

- 结果页显示阶段进度（取序列 → 折叠预测 → 置信度分析），运行中可**两键取消**（点「取消」→ 点「确认取消」）。
- 失败的任务可点「↻ 重新提交」原样重跑。
- 提交后可以关页面吗？**不建议**——任务完成瞬间浏览器要把报告写入归档，提前关闭可能丢失归档（结果本身仍在，但换浏览器后看不到）。等出现评分徽标再关。

## 5. 结果页功能

- **3D 结构**：按 pLDDT 着色（蓝=高置信 → 红=低置信）、可拖拽旋转缩放、自动旋转开关、全屏。
- **置信度曲线 + 序列条**：鼠标悬停 3D 与曲线联动；序列条可拖选区段聚焦。
- **分段统计**：连续低置信区段（pLDDT<70）自动列出。
- **导出**：PNG（快照）/ CSV（逐残基数据）/ PDB（结构文件）；复合物另有 PAE 热图导出。
- **⇩ 分享报告**：生成自包含 HTML（含 3D 快照 + 评分 + 完整 JSON），可直接发邮件/进 PPT。
- **⇄ 与 AlphaFold DB 对比**（单体/批量展开行）：与实验参考结构做 RMSD 对齐；核心区 Cα-RMSD < 2 Å 即「与参考高度一致」。

## 6. 任务页与报告墙

- **任务页**（顶栏「全部任务」）：类型筛选 chips（全部/单体/复合物/批量/检索/对比，带计数）+ 标题/ID 搜索。
- **首页报告墙**：同样的类型筛选；每张卡带 Cα 主链缩略图与平均 pLDDT 评分。
- 历史归档在换浏览器/换设备后依然完整可看（点开即重建交互结果页）。

## 7. 检索页

按关键词搜 UniProt（如 `hemoglobin`）→ 行内 ▶ 一键预测该条目；勾选多条可「▶ 预测所选」自动升级为批量任务。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 提交按钮灰色 | 输入未通过识别——看输入框下方的黄条提示 |
| 任务失败 | 看失败原因行，多数可「↻ 重新提交」；UniProt 网站偶发限流 |
| 序列太长报错 | ESMFold 建议 <400 aa；长链请拆域或用复合物模式 |
| 结果页空白 | 刷新一次；仍空白则截图反馈给负责人 |
| 删除按钮不见了 | guest 是只读账号，属正常设计 |

## 9. 测试建议路径

1. 首页粘贴 `P69905` → 单体预测 → 等 2–4 分钟 → 看评分与 3D。
2. 结果页点「⇄ 与 AlphaFold DB 对比」→ 看对比结论。
3. 切「复合物预测」粘贴示例两行序列 + 阿司匹林 SMILES → 看 PAE 热图。
4. 切「批量预测」粘 2–3 个 ID → 展开任意行 → 行内「⇄ 对比」。
5. 「⇩ 分享报告」下载 HTML 打开检查。
6. 全程记录：哪一步不直观、哪句话看不懂、哪里想点却没有。
