# 蛋白质科研 Agent · 系统使用指南

入口：浏览器打开 **http://127.0.0.1:4177** → 左侧选择 **protein-predictor** 工作区 →
底部输入框粘贴自然语言指令。Agent 自行决定调用哪个工具、按什么顺序执行；
每个工具的结果都会渲染成对应的**交互面板**（不是纯文本）。

---

## 0. 界面布局总览

| 区域 | 位置 | 内容 |
|---|---|---|
| 会话列表 | 左侧栏 | 历史对话，点击回看（面板可重放，截图/导出随时可用） |
| 对话流 | 中间 | 你的指令 + Agent 回复 + 嵌入的结果面板 |
| 输入框 | 底部 | 自然语言指令；`protein-predictor` 标签确认工作区正确 |

面板共 5 类：**搜索表、主置信度面板（单蛋白）、复合物面板、批处理表、对比卡**。
下面逐个讲清楚「怎么调 → 能力边界 → 面板上每个交互的作用」。

---

## 1. UniProt 搜索（uniprot_search / uniprot_fetch）

**什么时候用**：只知道蛋白名字（"胰岛素受体"），不知道 accession 和序列。

**怎么调**：
```text
我想研究人源胰岛素受体（insulin receptor），先搜一下 UniProt 找到
它的 accession，告诉我序列长度和物种，确认后预测结构。
```

**能力**：
- 按名字/关键词检索 UniProt 数据库，返回 accession、蛋白名、物种、序列长度
- `uniprot_fetch` 按 accession 取完整 FASTA 序列，供后续预测

**面板交互（搜索表）**：
| 操作 | 效果 |
|---|---|
| 点击表头 | 按 accession / 蛋白名 / 物种 / 长度排序（升 → 降 → 恢复相关度） |
| 点击任意行 | 复制该行 accession 到剪贴板 |
| 键盘：Tab 进表后 ↑↓ / Home / End | 行间移动焦点；空格勾选/取消批量勾选，回车复制 accession |
| 键盘：Tab 到表头后回车/空格 | 按 accession / 蛋白 / 物种 / 长度排序（与点击表头等效） |
| 勾选多行 →「复制批量预测指令」 | 自动生成一条 batch_predict 命令，粘回对话框即可一次预测多个 |
|「导出 CSV」 | 命中表按当前排序下载（accession/名称/物种/长度/UniProt 链接），直接进 Excel |
| 回复「预测 P61626」 | Agent 接着对该蛋白执行预测流程 |

## 2. 单蛋白预测 + 置信度分析（predict_structure / analyze_confidence）

**什么时候用**：已知 accession 或纯序列，想看 3D 结构和哪里可信。

**怎么调**：
```text
用 uniprot_fetch 获取 P61626 的序列，用 predict_structure 预测结构，
再用 analyze_confidence 分析置信度，用中文总结。
```
```text
帮我预测人 p53 蛋白（P04637）的结构，重点说明哪些区域置信度低、
可能是什么（柔性区/无序区），以及哪些区域可以放心用于建模。
```
也可以直接给序列：`预测这个序列的结构：MSTHDTSLTSTDILRGQVSAARFGLL…`

**能力与边界**：
- 引擎：ESMFold 免费端点，秒级返回
- **限制**：≥400 残基的长链会被免费端点拒绝（HTTP 413，如 P00439 苯丙氨酸羟化酶
  452 残基）。此时改用 `predict_complex`（Boltz-2 本地引擎可以折单链，约 4–6 分钟）
- 输出：`structures/<名字>.pdb`，面板直接渲染

**主面板交互速查**：

| 区域 | 操作 | 效果 |
|---|---|---|
| 3D 视图 | 拖拽 / 滚轮 / 双击 | 旋转 / 缩放 / 复位 |
| 3D 视图 | 悬停残基 | 读出 `链:残基 + pLDDT`，曲线与序列条同步高亮 |
| 3D 视图 | 点击残基 | 选中锁定（再点取消）；残基旁常驻标签，自动旋转也跟手 |
| 3D 视图 | 聚焦后按 ← → | 逐残基扫描，与曲线联动 |
| 3D 视图 |「⤢ 全屏」 | 结构投满整窗（组会/投屏）；Esc 或按钮退出 |
| 3D 工具栏 |「自动旋转」开关 | 暂停/恢复自转（截图、逐残基检查时用）；系统开了「减少动态」时默认不转 |
| 工具栏 | 配色下拉 | 按 pLDDT / 彩虹 (N→C) / 按链（多链时）/ 按界面误差（有 PAE 时） |
| 视图下方 | 图例 | 常驻当前配色的色标，随下拉自动切换 |
| 工具栏 | 残基号输入框 | 输入 `101` / `K101` / `B:17`（链:编号）回车直达；输入区段 `36-42` / `B:1-5`（链:区段）回车聚焦整段（曲线区段带 + 3D 段外淡化），再输一次取消 |
| 曲线 | 悬停 | 每残基 pLDDT 数值 + 分段参考线（90/70/50）与均值线（μ，贴近参考线时自动避让） |
| 曲线下 | 序列条 | 每残基一个着色 tile（单字母缩写），与 3D、曲线三向联动 |
| 序列条 | 点击 / 悬停 | 同选中 / 高亮（与 3D、曲线联动） |
| 序列条 | 按下拖过一片 tile | 松手即聚焦该区段（曲线区段带 + 3D 段外淡化；跨链拖选忽略），再输一次同区段、点同款 chip 或点「聚焦区段」标签取消 |
| 序列条 | 按下拖过一片 tile（批处理下钻） | 下钻面板同样支持：拖选后曲线与该蛋白的 3D 同步聚焦 |
| 序列条 | 聚焦后 ← → / Home / End | 键盘逐残基扫描（Tab 聚焦，回车选中，Esc 退出） |
| 概览区 | 低置信区段 chip | 点击后曲线画出橙色区段带，3D 中段外残基淡化为灰色——整段折叠一眼可读 |
| 概览区 |「复制结论」 | Markdown 结论（均值、四段分布、低置信区段、判读、文件路径） |
| 3D 工具栏 |「导出 PNG」「复制图像」「复制序列」 | 合成图自带图例；FASTA 可直接进 BLAST |
| 曲线工具栏 |「复制图像」「导出 PNG」「导出 CSV」 | CSV 为逐残基 `residue,aa,plddt` 原始数值 |

**着色配色读法**：pLDDT ≥90 深蓝（可直接建模）· 70–90 浅蓝（骨架可靠）·
50–70 黄（谨慎，可能柔性）· <50 橙红（大概率本质无序）。

## 3. 复合物 / 蛋白-配体预测（predict_complex，Boltz-2）

**什么时候用**：多条链的复合物、蛋白+小分子配体、或单链长蛋白（ESMFold 折不动的）。

**怎么调**：
```text
用 predict_complex 预测这两条链的复合物：
MKTAYIAKQRQISFVKSHFSRQ，EIAJKQGQVTMVIKKSMLEK，
配体 SMILES 是 CC(=O)OC1=CC=CC=C1C(=O)O。给出结合置信度。
```

**引擎选择（自动）**：
- 配置了 API key（`$AGH_HOME/secrets/boltz/default`，权限 600，或环境变量
  `BOLTZ_API_KEY`）→ 走云端 api.boltz.bio，快、支持 >500 残基大复合物
- **没配 key → 自动用本机开源权重**（boltz-community，Apple Silicon 走 MPS 加速），
  报告带 `engine: "boltz2-local"`；每个目标约 4–6 分钟，首次运行下载约 10 GB 权重

**长链回退**：ESMFold 报 413 的单链（≥400 残基）传给 predict_complex，本地引擎
可以折，报告只含 pTM 结构置信（无接口指标属正常）。

**任务等待**：复合物任务可能跑几分钟。`wait=false` 先拿 predictionId；
之后用 `prediction_id="<id>"`（附相同序列）再调用取结果，不会重复计费。

**复合物面板交互速查**：

| 区域 | 操作 | 效果 |
|---|---|---|
| 3D 视图 | 默认按链着色 | 图例显示每条链的残基数与平均 pLDDT；下拉可切回 pLDDT / 彩虹 / 界面误差 |
| 3D 视图 | 按界面误差着色（有 PAE 时） | 每残基按对其它链的平均 PAE viridis 着色——界面可信度在结构上直接读出 |
| 3D 视图 | 配体 | 按元素着色（C灰/O红/N蓝/S黄）；「配体 (N)」开关可隐藏；距配体 ≤6 Å 残基悬停显示距离；自动画配体到 5 Å 内残基的**口袋接触虚线** |
| PAE 热图 | 悬停任意格 | 读出残基对预测误差（Å），联动高亮 3D 与曲线 |
| PAE 热图 | 悬停 3D/曲线残基 | 热图画出对应行列十字线 |
| PAE 热图 | 点击「A–B 1.61 Å」链间芯片 | 框出该链对的两个对称误差块；再点取消。**低值 = 界面建模可信**（药物靶点关键信号） |
| PAE 热图 | 右侧误差条 | 逐残基平均误差（不含自身），长条 = 界面残基或无序区 |
| PAE 热图 |「⤢ 全屏」 | 投满整窗逐格检查（格子上限 24，Esc 退出） |
| 概览区 | pTM / ipTM / 结合置信度 chip | 结构置信 / 界面置信 / 结合可行性 |
| 工具栏 | 与单蛋白面板同款交互 | 残基号跳转（`B:17`）、区段聚焦（`B:1-5`，链前缀在复合物里必填）、序列条拖选、配色下拉、自动旋转、全屏、复制/导出全套 |

> PAE 怎么读：紫 = 低误差（可信），黄 = 高误差（≥32 Å 封顶）；虚线为链边界，
> 块外亮区提示接口或折叠不确定性。超过 800 残基的长链自动按块均值降采样
> （标题标注「每格 N 残基」）。

## 4. 批处理（batch_predict）

**什么时候用**：一次预测/比较多个蛋白（筛选、家族分析）。

**怎么调**：
```text
用 batch_predict 一次预测 P61626、P04637 和 P0A7B8 三个蛋白，
然后按平均 pLDDT 排序，每个用一句话点评。面板里点击行可展开 3D 结构。
```
（也可以从搜索表勾选多行自动生成指令。）

**能力**：
- 逐个调用预测引擎并汇总；单个失败不影响整体（失败行附原因，
  如 `ESMFold HTTP 413` = 序列过长）
- 排序下拉：默认顺序 / 按平均 pLDDT

**批处理表交互**：

| 操作 | 效果 |
|---|---|
| 看行 | 蛋白名、残基数、平均 pLDDT 徽章、迷你置信度条（色带同 3D 着色）、状态 |
| 点击某行 | 就地展开该蛋白的 3D + 曲线（功能与单蛋白面板完全一致：全屏/配色/残基跳转/区段聚焦/序列条拖选/复制全都有） |
| 键盘：Tab 进表后 ↑↓ / Home / End | 行间移动焦点；回车 / 空格展开或收起该蛋白的下钻面板 |
|「复制结论」 | Markdown 批处理总结：完成数、各蛋白均值、逐蛋白表格（含失败行及原因） |
|「导出 CSV」 | 整表下载，直接进 Excel/表格软件 |

## 5. 结构对比（compare_alphafold / compare_structures）

**什么时候用**：
- 预测结果 vs AlphaFold 数据库参考（检验预测质量、找分歧区）→ `compare_alphafold`
- 任意两个 PDB：突变体 vs 野生型、两种构建体 → `compare_structures`

**怎么调**：
```text
预测 P04637 的结构，然后用 compare_alphafold 和 AlphaFold DB 参考
对比，解释全链 RMSD 和核心 RMSD 为什么差这么多（提示：无序区）。
```
```text
对比 structures/p53_human_P04637_393aa.pdb（WT）和
structures/p53_R248W_393aa.pdb（R248W 热点突变体），label 分别设为
「WT」和「突变体」，说明折叠是否一致、置信度分歧最大的残基在哪里。
```

**能力**：
- 序列比对 + Cα 叠合，输出全链 RMSD、核心 RMSD（只算 pLDDT≥70 残基）、
  平均 ΔpLDDT、分歧最大残基
- 预测侧含配体时，对比 3D 同样按元素渲染配体（与单蛋白面板一致）

**对比卡交互速查**：

| 区域 | 操作 | 效果 |
|---|---|---|
| 叠合 3D | 悬停残基 | 读出双侧 pLDDT、Δ、Cα 偏差；参考模型显示为灰色 |
| 叠合 3D | 点击「分歧最大残基」chip | 3D 中定位该残基 |
| 镜头切换 | 置信度差异 / Cα 偏差 芯片 | 前者按 ΔpLDDT 方向着色分歧序列条（**蓝=预测/结构A 更自信，橙=参考/结构B 更自信**，色浓=分歧大）；后者按叠合后 Cα 距离着色（teal ≤0.5 Å → 红 ≥5 Å），**且 3D 参考链同步换成距离着色**——折叠变化直接读成空间热点 |
| 分歧序列条 | 悬停/点击 | 每残基数值读出（含双侧 pLDDT 与带符号 Δ）；点击定位到 3D |
| 工具栏 |「复制结论」「导出 PNG」「导出 CSV」 | 结论含双侧 label、两个 RMSD、分歧残基；PNG 文件名跟随当前镜头 |

> RMSD 怎么读：无序区会拉高全链 RMSD；判断折叠是否一致要看核心 RMSD。

## 6. 导出体系（所有面板通用）

| 按钮 | 在哪里 | 给你什么 |
|---|---|---|
| 复制结论 | 主面板 / 批处理 / 对比卡 / 下钻 | Markdown 分析结论，粘进论文/纪要/实验记录 |
| 复制图像 | 3D / 曲线 / PAE / 对比卡工具栏 + 下钻 | 与「导出 PNG」同一张合成图（自带图例色标）直接进剪贴板，Ctrl-V 即贴 |
| 导出 PNG | 同上 | 合成图文件下载（3D、曲线+序列条、PAE+误差条+图例、对比叠合长图） |
| 导出 CSV | 曲线 / 批处理 / 对比卡 / PAE / 搜索 | 逐残基原始数值（pLDDT、interface_pae、Cα 距离、Δ）或命中表（搜索），进 Excel/Python |
| 复制序列 | 3D 工具栏 | FASTA（多链按链分条 `_A`/`_B`，60 列换行），进 BLAST/建模工具 |
| 下载 PDB | 主面板 / 批处理下钻 / 对比卡 3D 工具栏 | 工作区里的原始结构文件（.pdb），直接进 PyMOL/ChimeraX/分子对接软件；浏览器远程访问（服务器部署）时也能取到文件 |

设计原则：每张导出图**自带图例**，单看图片即可读懂，不需要回原文解释。

## 7. 结果判读速记（面板里也写进了「复制结论」）

- 平均 pLDDT ≥90 高置信；70–90 骨架可靠、局部待验证；<70 谨慎
- **pLDDT<50 的区段大概率是无序区，不是预测失败**——无序区常是功能位点
- 对比任务看**核心 RMSD** 而不是全链 RMSD
- PAE：链间块亮 → 该界面不可信；链间芯片数值低 → 界面可信
- 计算结果 ≠ 实验结论；突变设计等实验决策需要湿实验验证

## 8. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 预测报 `ESMFold HTTP 413` | 序列 ≥400 残基超免费端点限制；改用 predict_complex 走本地 Boltz-2（单链约 4–6 分钟） |
| 复合物等很久 | 本地引擎每目标 4–6 分钟属正常；`wait=false` 先拿 predictionId，之后再取 |
| 未配 Boltz key 的提示 | 工具返回配置指引；key 放 `$AGH_HOME/secrets/boltz/default`（600）或 `BOLTZ_API_KEY` |
| 面板里的图看着小 | 用各视图的「⤢ 全屏」投满整窗 |
| 很长的蛋白（600+ aa）面板会卡吗 | 不会。序列条超过 800 残基自动切密集模式（tile 变小），PAE 热图超过 800 残基按块均值降采样并在标题标注「每格 N 残基」，导出 PNG/CSV 不受影响 |
| 想批量预测多个 | 搜索表勾选多行生成指令，或直接写 batch_predict + 多个 accession |
| 手机浏览器打开会不会乱 | 不会。面板按自身宽度自适应，窄屏自动变单列，340px（小手机）起即完整可用、无横向滚动 |
| 深色模式下面板刺眼吗 | 不。面板跟随宿主的配色设置（设置页「配色」：跟随系统/浅色/深色）自动切换深色主题；曲线/PAE 等 canvas 图保留白底「论文图卡」样式，导出 PNG 在两种主题下完全一致 |
