# 使用示例 / Example prompts

在 protein-predictor 工作区直接粘贴到对话输入框即可。`P04637` = 人 p53，
`P61626` = 人溶菌酶 C（快速、高置信，适合演示）。

## 基础流程：取序列 → 预测 → 置信度分析

```text
用 uniprot_fetch 获取 P61626 的序列，用 predict_structure 预测结构，
再用 analyze_confidence 分析置信度，用中文总结。
```

```text
帮我预测人 p53 蛋白（P04637）的结构，重点说明哪些区域置信度低、
可能是什么（柔性区/无序区），以及哪些区域可以放心用于建模。
```

## 只知道蛋白名：先搜索

```text
我想研究人源胰岛素受体（insulin receptor），先搜一下 UniProt 找到
它的 accession，告诉我序列长度和物种，确认后预测结构。
```

搜索结果以结构化表格呈现：点击任意行即可复制 accession，
点击表头按 accession/蛋白/物种/长度排序（升→降→恢复相关度排序），
勾选多行后点「复制批量预测指令」直接生成 batch_predict 命令，
粘贴到对话框即可一次预测多个；回复「预测 <accession>」继续下一步。

## 批处理：一次预测多个蛋白

```text
用 batch_predict 一次预测 P61626、P04637 和 P0A7B8 三个蛋白，
然后按平均 pLDDT 排序，每个用一句话点评。面板里点击行可展开 3D 结构。
```

## 与 AlphaFold DB 对比

```text
预测 P04637 的结构，然后用 compare_alphafold 和 AlphaFold DB 参考
对比，解释全链 RMSD 和核心 RMSD 为什么差这么多（提示：无序区）。
```

## 任意两结构对比（突变/构建体研究）

```text
对比 structures/p53_human_P04637_393aa.pdb（WT）和
structures/p53_R248W_393aa.pdb（R248W 热点突变体，ESMFold 预测）
（compare_structures），label 分别设为「WT」和「突变体」，
说明折叠是否一致、置信度分歧最大的残基在哪里。
```

## 复合物 / 蛋白-配体（Boltz-2）

配置了 API key 时走云端（快、支持大复合物）；**未配置密钥时自动使用本机开源权重**
（`boltz-community`，Apple Silicon 走 MPS 加速）：报告带 `engine: "boltz2-local"`，
指标口径与云端一致，但每个目标需数分钟、首次运行会下载约 10GB 权重，大复合物（>500 残基）
建议配 key。

```text
用 predict_complex 预测这两条链的复合物：
MKTAYIAKQRQISFVKSHFSRQ，EIAJKQGQVTMVIKKSMLEK，
配体 SMILES 是 CC(=O)OC1=CC=CC=C1C(=O)O。给出结合置信度。
```

未配置密钥时，工具会返回配置指引（密钥放
`$AGH_HOME/secrets/boltz/default`，权限 600，或环境变量 `BOLTZ_API_KEY`）。

复合物任务可能跑几分钟：`wait=false` 先拿 predictionId；之后（或收到超时提示时）
用 `prediction_id="<id>"`（附相同 sequences）再调用即可取结果，不会重复提交计费。

## 面板交互速查

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮 / 双击 3D 视图 | 旋转 / 缩放 / 复位 |
| 悬停曲线或 3D 残基 | 双向联动高亮 + pLDDT 数值（多链复合物显示 `链:残基`，如 `B:GLY1`） |
| 悬停/点击曲线下方序列条 | 每残基一个 pLDDT 着色 tile（单字母缩写），与 3D、曲线三向联动；链交界有空隙 |
| 多链复合物面板 | 自动按链着色并显示图例（每条链的残基数与平均 pLDDT）；下拉可切回 pLDDT 着色 |
| 点击低置信区段 chip | 曲线与 3D 同步聚焦该区段 |
| 工具栏「跳转残基」输入编号回车 | 直接选中该残基（多链复合物用 `B:17` 指定链；单链也认 `K101` 氨基酸+编号） |
| 点击 3D 残基 / 面板聚焦后按 ←→ | 选中该残基并保持读出（再点一次取消）；方向键逐残基扫描，与曲线高亮联动 |
| 「导出 PNG」 | 3D 图保存为图片（多链复合物自动把链图例合成进图）；曲线导出会**把序列条合成到图下方**（图+热区一体，论文/组会可用） |
| 「复制序列」 | 复制 FASTA（多链复合物按链分条 `_A`/`_B`，60 列换行），可直接进 BLAST/建模工具 |
| 曲线工具栏「导出 CSV」 | 每残基 pLDDT 原始数值（`residue,aa,plddt`，多链带链前缀），进 Excel/Python 直接分析 |
| 点击「分歧最大残基」chip | 在 3D 叠加中定位该残基，读出行显示双侧 pLDDT 与 Δ |
| 对比卡 3D 下方的分歧序列条 | 每残基按 \|ΔpLDDT\| 蓝→橙红着色——无序区/分歧热区一眼可见；悬停显示双侧数值与 Cα 偏差，点击定位。顶部芯片可切换 **置信度差异 / Cα 偏差** 两种镜头：后者按叠合后 Cα 距离着色（teal ≤0.5 Å → 红 ≥5 Å），且 3D 里的参考链同步换成距离着色——折叠本身的变化（突变体位移、域挪动）在三维空间直接读成热点 |
| 对比卡 3D 工具栏「导出 PNG」 | 叠合 3D + 镜头图例行 + 分歧序列条合成一张深色长图，论文/组会直接可用；文件名跟随当前镜头（`*.plddt.png` / `*.cadist.png`） |
| 对比卡「导出 CSV」 | 每残基原始数值：双侧 pLDDT、Δ、叠合后 Cα 距离（`*.compare.csv`），可直接进 Excel/Python 做进一步分析 |
| 对比卡「复制结论」 | 一键复制 Markdown 格式的对比结论（双侧 label、全链/核心 RMSD、平均 Δ、结论、分歧最大残基），直接进论文/纪要 |
| 批处理卡片「导出 CSV」 | 整表下载为 CSV（含失败行及原因，可直接进表格软件） |
| 批处理卡片点击某行 | 就地展开该蛋白的 3D + 曲线（各带「导出 PNG」，与单蛋白面板一致） |

## 结果判读速记

- 平均 pLDDT ≥90 高置信；70-90 骨架可靠、局部待验证；<70 谨慎
- pLDDT<50 的区段大概率是无序区，不是预测失败
- 对比任务看 **核心 RMSD**（pLDDT≥70 残基）而不是全链 RMSD——无序区会
  拉高全链数值
- 计算结果 ≠ 实验结论；突变设计等实验决策需要湿实验验证
